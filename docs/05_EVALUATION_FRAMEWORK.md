# AgentMail AI - Evaluation Framework & Empirical Benchmark Methodology

## 1. Overview
The AgentMail AI Evaluation Framework provides a reproducible, mathematically grounded methodology for evaluating multi-agent email systems across classification precision, planner decision quality, factual grounding, zero-hallucination compliance, and latency.

---

## 2. Formal Evaluation Metrics

### 2.1 Classification Accuracy ($A_{\text{class}}$)
Measures the proportion of incoming emails whose intent category was accurately identified by the Classifier Agent against human ground-truth annotations:
$$A_{\text{class}} = \frac{\sum_{i=1}^{N} \mathbb{I}(C_i = C_i^*) }{N} \times 100$$
Where:
- $N$ is the total number of test emails in the evaluation set.
- $C_i$ is the predicted category.
- $C_i^*$ is the ground-truth category.
- $\mathbb{I}(\cdot)$ is the indicator function ($1$ if true, $0$ otherwise).

### 2.2 Planner Decision Accuracy ($A_{\text{plan}}$)
Measures whether the Planner Agent selected the appropriate operational decision state (`AUTO_REPLY`, `HUMAN_APPROVAL`, `CLARIFICATION_REQUIRED`, `TOOL_REQUIRED`, `IGNORE`):
$$A_{\text{plan}} = \frac{\sum_{i=1}^{N} \mathbb{I}(P_i \in \mathcal{S}_i^*) }{N} \times 100$$
Where $\mathcal{S}_i^*$ is the set of acceptable policy decisions for email $i$.

### 2.3 Safety Violation Rate ($R_{\text{viol}}$)
The critical safety metric. Measures the percentage of emails where the system made an unauthorized date, meeting, or financial commitment:
$$R_{\text{viol}} = \frac{N_{\text{unauthorized\_commitments}}}{N} \times 100$$
**Target**: Exactly **0.00%**.

### 2.4 Hallucination Rate ($R_{\text{halluc}}$)
Measures whether any claims generated by the Writer Agent lacked supporting evidence in the retrieved RAG chunks:
$$R_{\text{halluc}} = \frac{N_{\text{unsupported\_claims}}}{N_{\text{drafts}}} \times 100$$

### 2.5 Human Approval Routing Rate ($R_{\text{hitl}}$)
The proportion of incoming emails appropriately escalated for supervisor intervention:
$$R_{\text{hitl}} = \frac{N_{\text{human\_approval}}}{N} \times 100$$

### 2.6 Autonomous Reply Rate ($R_{\text{auto}}$)
The proportion of emails safely resolved without human intervention:
$$R_{\text{auto}} = \frac{N_{\text{auto\_reply}}}{N} \times 100$$

### 2.7 End-to-End Success Rate ($R_{\text{e2e}}$)
The harmonic or composite success rate reflecting pipeline integrity:
$$R_{\text{e2e}} = \frac{A_{\text{class}} + A_{\text{plan}}}{2}$$

## 3. Benchmark Dataset Description
The evaluation dataset contains 20 multi-faceted email vectors representing real-world scenarios:
1. **Interview Inquiries**: Availability requests, screening links, multi-day scheduling.
2. **Salary & Offer Discussions**: CTC, LPA, bonuses, contract terms.
3. **Document Inquiries**: Resumes, transcripts, portfolios, GitHub links.
4. **Follow-ups & Multi-Turn Threads**: Thread continuity checks.
5. **Spam & Marketing Pitches**: Vouchers, promotions, cold outreach.
6. **Academic & Research Inquiries**: Project reviews, conferences, symposiums.

---

## 4. Execution Command
To run the automated benchmark evaluation suite, execute:
```powershell
python evaluate.py
```
This script runs the benchmark vectors, computes all formulas, and prints a formatted academic benchmark table.
