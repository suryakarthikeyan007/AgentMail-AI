# Major Projects

## 1. AgentMail AI: Intelligent Agentic Email Management System (Final Year Project)
- **Role**: Lead Architect and Full-Stack Developer
- **Stack**: Python, FastAPI, Llama 3.1 (Ollama), nomic-embed-text, n8n, SQLite, HTML5/CSS3 Dashboard.
- **Overview**: An enterprise-grade agentic email management system following the CLASSIFY → RETRIEVE → REMEMBER → PLAN → DECIDE → ACT → VERIFY → REMEMBER lifecycle. Employs an explicit Planner Agent with 5 distinct deterministic decisions (Auto-Reply, Human Approval, Clarification Required, Tool Required, Ignore), zero-hallucination safety gates, and thread-aware conversation memory.

## 2. DocuRAG: Enterprise Document Question-Answering System
- **Role**: Backend & AI Developer
- **Stack**: Python, LangChain, FAISS, Ollama, FastAPI.
- **Overview**: High-throughput semantic search and citation-backed question answering over corporate PDF repositories with hybrid BM25 + dense embedding re-ranking.

## 3. Autonomous Code Reviewer Bot
- **Role**: Solo Developer
- **Stack**: Python, GitHub Webhooks, Llama 3, Docker.
- **Overview**: Automated PR assistant inspecting code diffs for security vulnerabilities, memory leaks, and PEP8 compliance before merge requests.
